# Referências oficiais

Estas fontes externas orientam contratos e comportamento do renderer Android.
Elas são referências de design e semântica; o Megalodonte continua expondo sua
API Java neutra e renderizando views nativas, sem exigir Jetpack Compose do app.

## Entrada de texto

- [Processar entradas do usuário — Android Developers](https://developer.android.com/develop/ui/compose/text/user-input?hl=pt-br): variantes preenchida e contornada, estado do texto, opções IME e `onKeyboardAction` com execução opcional da ação padrão.

## Switch

- [Switch — Android Developers](https://developer.android.com/develop/ui/compose/components/switch?hl=pt-br): estado marcado/desmarcado, callback de mudança, habilitação e cores de thumb/track.
